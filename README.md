# MickChen's Homebrew Tap

Personal Homebrew tap for tools not yet (or no longer) in homebrew-core.

## Available Formulae

| Formula | Description | Source |
| --- | --- | --- |
| [`crush`](Formula/crush.rb) | AI-powered coding assistant for the terminal | [charmbracelet/crush](https://github.com/charmbracelet/crush) |

## Install

```bash
brew tap MickChen/tap
brew install crush
```

## Auto-update

```bash
brew autoupdate --start 43200   # check for upgrades every 12 hours
```
